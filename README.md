Student Record Management System

A command-line Java application for managing student data in a structured and user-friendly way. This system supports essential CRUD operations (Create, Read, Update, Delete) and uses core Java concepts like classes, collections, and input handling. Developed as part of a learning project to practice data structure implementation and basic application design.

📚 Overview

The application allows users to:

Add student records with ID, name, and marks

View all student records

Update existing student details

Delete student records by ID

Data is stored in-memory using an ArrayList, making this a lightweight and fast solution—but not persistent. The program runs entirely in the console/terminal.
